What is an ESP32?

What is an ESP32?
The ESP32 is a small, cheap microcontroller made by the company 'Espressif Systems'. A microcontroller is a tiny computer on a chip that controls things like LED's, motors and sensors. The ESP32 is special because it has Wi-Fi and Bluetooth built in, so it can connect to the internet without any extra parts. It was released in 2016 and a board usually costs around NZ$6 to NZ$20.

Main features

- Two processor cores running up to 240 MHz
- Built-in Wi-Fi and Bluetooth
- About 30 pins (depending on model) for connecting LEDs, buttons and sensors
- Runs on 3.3 V. It can be powered through USB or via an external battery
- Has a sleep mode that uses very little power, so it can run on batteries, while keeping vital tasks running
- It emulates EEPROM behavior, meaning it can store data straight on the board that stays even when power is disconnected

What its used for

- Smart home devices like lights and plugs
- Weather stations and other sensors that send data online
- Robots and remote controlled cars
- Small cameras
- School and hobby projects
