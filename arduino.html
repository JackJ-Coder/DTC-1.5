What is an Arduino?

A small, beginner-friendly circuit board for building electronics projects.

What it is

An Arduino is a small circuit board with a microcontroller on it. A microcontroller is a tiny computer on one chip that is built to control things like lights, motors and sensors. You write a short program on your computer, upload it to the board, and the Arduino then runs it over and over.

Arduino started in 2005 in Ivrea, Italy, as a cheap and easy tool for design students who had no electronics background. It became one of the most popular ways in the world to learn electronics and programming, because both the boards and the software are simple to use and there are thousands of free tutorials online.

How does it work?

The microcontroller runs one program at a time, line by line. Your program is stored in flash memory, which keeps its contents even when the power is off, and it uses RAM as temporary working space while it runs. The Arduino has no operating system like Windows, so as soon as it is powered on it starts running your program.

The rest of the board makes the chip easy to use. It has a USB port for power and for uploading code, a voltage regulator that keeps the power steady, a reset button, a small built-in LED for testing, and rows of sockets along the edges for plugging in wires.

How does it connect to other parts?

The Arduino talks to the outside world through its pins. Each pin can be used as an input, such as reading a button or sensor, or as an output, such as switching on an LED.

  • Digital pins read or send simple on and off signals
  • Analog input pins read changing values, such as how bright a light is, as a number from 0 to 1023
  • PWM pins (marked with a ~) let you dim an LED or control the speed of a motor
  • Power pins provide 5 V and 3.3 V to run small parts
  • Shields are extra boards that plug straight on top and add features such as Wi-Fi, motor control or a screen

Beginners often connect parts using a breadboard, a plastic board with holes that lets you build circuits without any soldering.

What is it used for?

  • Learning: schools use Arduinos to teach electronics and programming
  • Robots: controlling motors, wheels and sensors that detect obstacles
  • Sensors and data loggers: recording temperature, light or soil moisture
  • Lights and displays: LED strips, small screens and signs
  • Home and hobby projects: alarms, automatic plant watering and remote controls
  • Prototypes: engineers use it to test an idea quickly before building the real thing

How do you program it?

You write your code in the free Arduino IDE on a computer, then upload it to the board with a USB cable. Programs are called sketches and are written in a version of C++ that has been made simple for beginners. There are also thousands of free libraries that add ready made code for common sensors and displays.

Example: making an LED blink

This is usually the first program people write. Every sketch has a setup() that runs once when the board starts, and a loop() that then repeats forever. 

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);   // the small LED on the board
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);   // LED on
  delay(1000);                       // wait one second
  digitalWrite(LED_BUILTIN, LOW);    // LED off
  delay(1000);
}

Popular boards

  • Arduino Uno: the classic beginner board, and the one most tutorials use
  • Arduino Nano: a much smaller board that fits on a breadboard
  • Arduino Mega: a larger board with many more pins, for big projects
  • Arduino Uno R4: a newer Uno from 2023 with a faster, more powerful chip, and a version with Wi-Fi

Interesting facts

  • The name comes from a bar in Ivrea where the founders often met.
  • It is open source, which means the designs are shared freely, so many other companies make compatible boards.
  • The classic Uno has no Wi-Fi or Bluetooth, so it needs an extra part to connect to the internet.
  • The Uno uses 5 V, but the ESP32 uses 3.3 V, so connecting the two directly needs care.
  • The Uno has only 2 KB of RAM, so programs have to be small and careful with memory.
  • It is not a full computer and has no operating system, so it can only run one program at a time.
  • Many 3D printers have been built around Arduino Mega boards.
