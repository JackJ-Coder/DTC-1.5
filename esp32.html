What is an ESP32?

A small, cheap computer chip with Wi-Fi and Bluetooth built in.

What it is

The ESP32 is a small, cheap microcontroller made by a company called Espressif Systems, which is based in Shanghai, China. A microcontroller is a tiny computer on one chip that is built to control things like lights, motors and sensors, rather than run programs the way a laptop does.

What makes the ESP32 special is that Wi-Fi and Bluetooth are built into the chip. Most small microcontrollers need extra parts to get online, but an ESP32 can connect to the internet straight out of the box. This made it very popular with students, hobbyists and engineers who want to build things that connect to the internet.

How does it work?

The ESP32 has two processor cores, which means it can do two jobs at the same time. For example, one core can look after the Wi-Fi connection while the other reads a sensor. Your program is stored in flash memory, which keeps its contents even when the power is off. While the program runs, it uses RAM as its temporary working space.

Most people buy the ESP32 on a development board. This adds a USB port for power and uploading code, a voltage regulator that turns the 5 V from USB into the 3.3 V the chip needs, a reset button, and rows of pins along the edges for connecting wires.

How does it connect to other parts?

The ESP32 talks to the outside world through its pins, called GPIO pins (General Purpose Input/Output). A typical board has about 30 usable ones. Each pin can be used as an input, such as reading a button or sensor, or as an output, such as switching on an LED.

  • Digital pins read or send simple on and off signals
  • Analog inputs read changing values, such as how bright a light is
  • Touch pins can sense a finger without needing a button
  • PWM lets you dim an LED or control the speed of a motor
  • Communication pins (I2C, SPI and UART) let it talk to displays, sensors and other chips

What is it used for?

  • Smart home devices: lights, plugs and door sensors you can control from your phone
  • Weather stations: reading temperature and humidity and sending the results online
  • Plant monitors: measuring soil moisture and sending an alert when a plant needs water
  • Robots and remote controlled cars: controlled over Wi-Fi or Bluetooth
  • Cameras: boards such as the ESP32-CAM can stream video for a very low price
  • School and hobby projects: alarms, clocks and small displays

How do you program it?

You write your code on a computer and upload it to the ESP32 with a USB cable. There are three main ways to do it:

Arduino IDE

The easiest way to start. It uses the same simple commands as an Arduino, so anyone who has used an Arduino can pick it up quickly.

MicroPython

Lets you write in the Python language instead, which many beginners find easier to read.

ESP-IDF

Espressif's official tool, used for more advanced and professional projects.

Example: making an LED blink

This is usually the first program people write. Every Arduino-style program has a setup() that runs once when the board starts, and a loop() that then repeats forever. 

const int ledPin = 2;      // the built-in LED on most boards

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);   // LED on
  delay(1000);                  // wait one second
  digitalWrite(ledPin, LOW);    // LED off
  delay(1000);
}

Other versions

Since the original chip, Espressif has released several newer versions:

  • ESP32-S2: One core, Wi-Fi only, with built-in USB support
  • ESP32-S3: Two cores, with extra features that help with AI and machine learning
  • ESP32-C3: A cheaper single-core, miniature version for extreamly small projects
  • ESP32-C6: Has support for the newer Wi-Fi 6

Interesting facts

  • It is the successor to the ESP8266, which was first sold as a simple Wi-Fi add-on for Arduinos before people found out it could run programs by itself.
  • It costs about the same as a basic Arduino but has Wi-Fi and Bluetooth as well.
  • It is not a full computer. It has no operating system like Windows, although it can run a small system called FreeRTOS.
  • Its pins only handle 3.3 V, so connecting 5 V to them can damage it.
  • It only connects to 2.4 GHz Wi-Fi, not 5 GHz.
  • In deep sleep it uses only a tiny amount of power, so a battery project can last for a long time.
  • It can host its own web page that you open from your phone to control it.
